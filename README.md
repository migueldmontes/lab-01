Vamos a crear nuestro primer HTML usando Visual Studio Code.

Cuando lo tengas, deberás también crear un repositorio usando github para poder entregarlo. Para ello, sigue estos pasos: 


1. Instala Gitbash

2. Accede a www.github.com

3. Accede a "Respositories"

4. Crea un nuevo repositorio dándole a "New"

5. Ponle como nombre "lab-01" y dale a crear repositorio. 

6. Copia la url de tu repositorio recién creado.

7.  Trabaja en el proyecto hasta finalizarlo.

8. Sube los cambios desde Visual Studio Code.
